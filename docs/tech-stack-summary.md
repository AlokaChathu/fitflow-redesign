# Technology Stack Summary

| Layer | Technology | Purpose |
|---|---|---|
| Mobile | React Native + TypeScript | Cross-platform Android/iOS application |
| Web | React + TypeScript | Browser-based FitFlow interface |
| Backend | Node.js + NestJS | Main API, business logic, authorization |
| AI Service | Python + FastAPI | Recommendations and AI/ML workloads |
| Primary Database | PostgreSQL | Structured authoritative application data |
| Real-Time Services | Firebase | Social feeds, challenges, live updates, notifications |
| Authentication | Firebase Authentication | Identity, social login, MFA-capable authentication |
| Cache | Redis | Frequently requested data and selected session data |
| AI/ML | TensorFlow Lite / suitable cloud ML models | On-device or cloud model inference |
| Media | Secure object storage | Meal photos and social media assets |
| API | REST + WebSocket/Firebase events | Standard and real-time communication |
